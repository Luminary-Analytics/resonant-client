# Resonant 0.16.0

This release makes saved projects and sessions easier to reach, preserves unfinished messages, and introduces the new teal Resonant wave mark.

- Named project rows, sidebar search, project/session command-palette results, and filters for current-project, all-project, and pinned sessions.
- Saved navigation loads before model discovery; project selection appears before model preparation completes. Large session lists render incrementally and preserve focus and scroll position.
- Unsent text is saved separately for each project and session and survives desktop restarts. Image attachments are not persisted as drafts.
- Desktop and compact sidebar preferences persist, and collapsed controls are excluded from keyboard navigation and assistive technology.
- Editable project notes include build/test commands, conventions, and recurring fixes. Recall selects at most six relevant, current notes within a small context budget; source freshness does not imply successful verification.
- Updated Resonant branding, application icon, and favicon.

Validation: 3,140 Python tests and four frontend recovery tests passed, along with browser checks and clean Windows bundle smoke tests. Nine isolated packaged startup runs covered offline providers, a responding protocol fixture, and a 10,000-event conversation. Live model loading and generation were not measured because the configured model servers were unavailable.

See [navigation measurements](ui-performance-pass-2026-09-05.md) and [recovery validation](recovery-validation-2026-09-08.md) for details and measurement limits.
