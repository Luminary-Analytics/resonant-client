# Resonant Client v0.11.11

The second restructuring release, and the one that finishes the work v0.11.10
started. No behaviour changes.

## What moved

- The WebSocket layer is no longer one function. The connection handler was
  2,186 lines dispatching 58 commands through a single chain; it is now 606
  lines handling 5, with the rest registered as individual handlers that can be
  read and tested on their own.
- The five that remain are the ones that genuinely belong there: they start a
  streaming run or wire the autonomous session's event forwarding to the live
  connection.
- The autonomous-session interface code — mission lifecycle, roadmap inspector,
  decision cards, health indicators — moved out of the main frontend file into
  its own.

The interface server's main module is down from 4,241 lines to 2,655; across
both restructuring releases, from 9,287. The frontend's main file is down from
14,500 to 12,427.

## Why the commands could not be separated before

They were not conceptually tangled with the connection loop. They needed to
read a handful of variables that only code physically inside that one function
could see. Naming that state — the pending message queue, the in-flight turn,
the cancellation bookkeeping — turned the dependency into an ordinary one, and
the commands followed.

That state is also now testable on its own: message ordering, a queued message
starting only when the previous turn ends, a cancellation being acknowledged
when the turn actually stops rather than when it was requested, and a failed
turn leaving the queue usable. As closures inside the connection handler, none
of that could be tested at all.

## Incidental fixes

- A dead assignment in the autonomous dispatch path, invisible to static
  analysis while unrelated code in the same 2,400-line scope reused the name.
- Several tests asserted on line ranges inside a source file and broke whenever
  code moved. They now inspect the function that actually serves the command.

## Validation

- Full Python suite: 2,917 passed, 2 platform-skipped. Ruff clean.
- Every relocated read-only command verified round-tripping against a running
  server with no errors, and the interface confirmed loading with its sidebar,
  sessions, and composer intact — the checks that matter when the entire claim
  is that nothing behaves differently.
