# Resonant Client v0.9.7

This patch makes user questions a last resort instead of the default way an
agent resolves implementation decisions.

## Highlights

- Requires agents to inspect relevant code, documentation, tests,
  configuration, project instructions, and git history before asking.
- Directs agents to follow established project patterns and use reasonable,
  reversible defaults for implementation details.
- Prevents confirmation, permission, obvious-next-step, and serial grill
  questions when the repository already provides enough evidence.
- Requires the agent to make its own evidence-based recommendation when the
  user asks for one.
- Retains Resonant's native multiple-choice prompt for genuinely unknowable,
  consequential decisions and records a private unresolved-reason audit note.
