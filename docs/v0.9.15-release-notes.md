# Resonant Client v0.9.15

## Faster, more controllable long-running sessions

- Adds a Usage & Cost dashboard with session, daily, and tracked-total token and cost history.
- Makes saved-session navigation resilient when a configured model provider is offline or slow to initialize.
- Lets users remove queued follow-ups and pending steering messages without interrupting the active run.
- Coalesces high-frequency streaming deltas into responsive frames, reducing WebSocket and browser overhead.
- Caches lightweight session metadata so large session histories no longer need repeated sidebar parsing.
- Makes incremental repository indexing reuse unchanged file hashes and eliminates the redundant second tree walk.
- Replaces quadratic dependency-map construction with an indexed implementation and caches stable repo maps.

## Performance measurements

- A 2,000-file dependency map improved from about 3,008 ms to 18 ms in a synthetic benchmark.
- A 500-session current/all-session refresh improved from about 150 ms to 41 ms.
- An unchanged 2,000-file reindex completed without reopening source files for hashing.

## Validation

- Full Python test suite passed: 2,724 passed and 2 skipped.
- Focused Ruff checks, Python compilation, JavaScript syntax, and diff validation passed.
