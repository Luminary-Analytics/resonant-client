# Resonant Client v0.11.15

Browsing is built in again — and this time it costs nothing to ship.

## Browser tools are native

Resonant drives your installed Chrome directly. Twelve tools are back:
`browser_navigate`, `browser_click`, `browser_type`, `browser_read`,
`browser_screenshot`, `browser_js`, `browser_scroll`, `browser_hover`,
`browser_select`, `browser_wait`, `browser_back`, and `browser_tabs`. Nothing
to install, no server to configure, no URL to paste — Chrome starts on first
use.

Browser support was removed in v0.9.13 because the implementation depended on
Playwright, which "adds 150+ MB and a Chromium download". That dependency was
being used purely as a protocol client. The DevTools protocol is JSON-RPC over
a WebSocket, so the replacement is built on `httpx` and `websockets`, both of
which Resonant already ships. **The installer does not grow.**

Practical notes:

- **Clicking works by visible text.** `browser_click` targets the smallest
  element showing the text you name, which survives the markup changes that
  break CSS selectors. Selectors and raw coordinates still work.
- **`browser_read` has an `accessibility` mode** that lists the page's
  interactive elements and their labels — usually the fastest way to decide
  what to click next, and far cheaper than a screenshot.
- **Chrome runs under a dedicated Resonant profile**
  (`~/.resonant/browser-profile`), not your everyday one. Chrome locks a
  profile directory while it is in use, so sharing yours would mean you and the
  agent could not browse at the same time. Log into sites once in that window
  and it persists.

## Agent tabs are grouped and labelled

Tabs the agent opens are collected into a single labelled, coloured Chrome tab
group, so they are obvious next to your own tabs. This needs a small bundled
extension: tab groups are the `chrome.tabGroups` extension API and are not
reachable through the DevTools protocol at all.

## Other changes

- **BrowserOS now ships disabled.** It was enabled by default when browsing
  required an external MCP server. Since browsing is native, leaving it on
  meant every user who never installed BrowserOS saw a "tool server not
  connected" notice for it. The configuration is still there — enable it and
  paste your URL if you prefer BrowserOS or another browser MCP.
- Desktop computer-use tools (screenshot, click, type, scroll, drag, hover,
  window focus, OCR) are unchanged and continue to ship.

## Validation

- Full Python suite: 2,956 passed, 2 platform-skipped. Ruff clean.
- Every tool exercised against real Chrome 150: navigation, text and
  accessibility reads, PNG capture, JavaScript evaluation, clicking by both
  visible text and CSS selector, history, waits, and tab open/list/switch.
- Tab grouping confirmed by querying the extension's own service worker —
  three tabs, one group titled "Resonant", all three in it.
- Clean-room bundle build passes the packaging gate with the extension present,
  and fails when it is removed.
