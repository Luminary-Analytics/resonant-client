# Resonant Client v0.8.1

This release makes ordinary coding turns more trustworthy and easier to recover.

## Highlights

- Classifies completed turns by their actual outcome instead of treating every stopped turn as done.
- Detects action promises that never produce a tool call and gives the model a bounded chance to continue.
- Requires write and validation evidence before showing **Changed & verified**.
- Adds **Retry**, **Retry another model**, and **Verify changes** recovery actions to incomplete turns.
- Uses a single guarded GLM/DeepSeek fallback for empty Full-auto responses.
- Records redacted provider-health telemetry without prompts, responses, or tool payloads.
- Deduplicates repeated file reads in model context while preserving complete tool output in the UI.
- Fixes blank provider responses and the synthetic **Task** card seen in saved chats.

## Quality

- Expanded deterministic coverage for turn outcomes, task-card rendering, telemetry, recovery, and context deduplication.
- Hardened a timing-sensitive verdict test for heavily parallel CI runs.
