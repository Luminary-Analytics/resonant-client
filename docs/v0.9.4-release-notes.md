# Resonant Client v0.9.4

This patch turns steering into true live direction for an active agentic run
instead of cancelling and restarting the task.

## Highlights

- Lets the current model inference or tool finish without interruption.
- Injects steering text into the same conversation history at the next safe
  agent-loop boundary.
- Tells the model to incorporate the added direction while preserving useful
  work already completed.
- Continues the same task card and run lifecycle instead of marking the
  original work Cancelled or starting a replacement turn.
- Keeps ordinary queued follow-ups as separate future turns.
- Shows when steering is waiting for a boundary and when it has entered the
  current model context.
- Preserves applied steering as a visible conversation note for session replay.
- Prevents cancelled or late steering messages from leaking into later tasks.

## Validation

- 121 steering, GUI, session-loop, cancellation, and tool-dispatch tests passed.
- A concurrent engine test verifies that an in-flight step completes normally
  and the next inference receives the steering context.
- JavaScript syntax and Git diff integrity checks passed.
