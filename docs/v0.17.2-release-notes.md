# Resonant 0.17.2

September 8, 2026. Choose a project when starting a new session.
[Release and Windows installer](https://github.com/Luminary-Analytics/resonant-client/releases/tag/v0.17.2).

## New-session project chooser

- New session and Ctrl+N offer a searchable list of existing projects, with
  paths and a current-project marker. Ctrl+N also works from the composer.
- Choose folder opens the desktop folder picker; browser mode falls back to an
  absolute-path field. The chosen folder becomes the new session's project.
- Cancelling preserves the current conversation and draft. Project-row plus
  buttons remain direct shortcuts, and conversations are saved on the first
  message, keeping empty drafts out of the sidebar.
- The welcome text follows the selected project even before a model is loaded.
- Updated the desktop guide and shared AGENTS.md instructions; CLAUDE.md
  continues to import AGENTS.md.
