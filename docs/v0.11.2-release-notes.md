# Resonant Client v0.11.2

## EXO distributed inference

- Adds EXO as a first-class OpenAI-compatible provider for local and distributed
  open models.
- Discovers running, downloaded, and supported EXO models, with running models
  shown first in Resonant's model picker.
- Automatically requests a valid EXO placement and waits for readiness when a
  selected model is downloaded but not running.
- Supports streamed text, native and parallel tool calls, usage reporting,
  cancellation-aware instance waits, and OpenAI-format image content.
- Keeps completion length under the selected model and provider's control
  without adding a Resonant-side output cap.

## Configuration and integration

- Adds the EXO endpoint to Settings, provider status, session persistence,
  harness routing, Director Mode, and sub-agent model selection.
- Supports `EXO_API_URL`, `EXO_BASE_URL`, and optional `EXO_API_KEY`
  configuration.
- Uses portable localhost defaults while allowing remote clusters through
  Settings or environment variables.

## Validation

- Full Python suite: 2,761 passed and 2 platform-skipped.
- Scoped Ruff, Python compilation, JavaScript syntax, and diff checks passed.
- Live EXO validation confirmed GLM 5.2 text generation, usage reporting, and a
  native function-tool call through the configured Mac Studio cluster.
