# Resonant Client v0.9.3

This release makes long-running conversations easier to direct and makes
agent questions behave like true one-click decisions.

## Highlights

- Adds an explicit model recommendation to multiple-choice questions, with a
  visible Recommended badge on the preferred option.
- Submits predefined choices immediately and replaces the reply controls with
  a clear selected/resumed acknowledgement.
- Keeps the working panel's animated shell mounted while its phase, progress,
  task list, and sub-task details update, eliminating animation restarts and
  visible flicker.
- Lets the normal composer arrow queue follow-up work without interrupting the
  active agent.
- Places queued follow-ups directly above the composer with their own Steer
  action, matching the Codex-style interaction.
- Promotes an exact queued message when Steer is selected and safely cancels
  the current turn before starting it.
- Keeps the composer available throughout active runs and queued transitions.
