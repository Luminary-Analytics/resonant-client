# Resonant Client v0.12.1

You can now see exactly where the agent is working, not just that it is.

## A ring around the cursor

v0.12.0 added a glow around the screen being driven. This adds the missing
half: while the agent has the mouse, a purple ring follows the real cursor, and
each click sends a brief ripple outward from it.

It is an outline, not a filled dot — the pointer and whatever it is hovering
stay visible underneath. The ripple fires **after** the click lands, at the
position the cursor actually reached, so a mis-click shows up as one rather
than being drawn where the agent intended to click.

Like the edge glow, the ring is click-through, follows the correct monitor, and
disappears for the instant a screenshot is taken so the model never sees
Resonant's own overlay in the image it is reading.

Both are covered by the same `computer_use_indicator` setting under **general**
and are on by default. Windows only; a no-op elsewhere.

## Worth knowing about computer use

Some questions came up that the documentation did not answer clearly, so to be
explicit: the desktop tools drive your **real** mouse and keyboard, not a
virtual device. Your physical pointer moves, keystrokes go to whichever window
has focus, and screenshots capture whatever is on screen. Scope is the whole
desktop — the path sandbox constrains file tools to your project, not desktop
input — and desktop actions do not pause for approval the way a force-push or
an `rm -rf` outside the project does.

The indicator exists precisely because of that. Nothing about the permissions
changed in this release.

## Validation

- Full Python suite: 3,000 passed, 2 platform-skipped. Ruff clean.
- Verified against the real cursor on a live desktop: the ring tracks it
  exactly when stationary and stays within one frame while moving, the click
  ripple expands and fades, and both the ring and the glow vanish from
  screenshots taken while they are lit.
- Ring geometry is covered by tests — it stays an annulus rather than a disc,
  its stroke is antialiased, and its pixels are premultiplied (un-premultiplied
  alpha would wash the ring out to white at the edges).
