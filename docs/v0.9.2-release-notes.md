# Resonant Client v0.9.2

This patch makes the live-run dock and its task list accurately reflect what
the agent is doing throughout iterative coding sessions.

## Highlights

- Forces the live "Resonant is working" surface into a full-width row directly
  above the composer instead of allowing flex layout to place it beside or
  below the prompt.
- Removes the legacy transcript-card ordering that could override the dock's
  DOM position.
- Keeps the status surface and composer aligned to the same content width with
  a consistent eight-pixel gap.
- Synchronizes fallback task labels with the current phase instead of leaving
  a stale "Finish the response" task visible during later reasoning steps.
- Reactivates inspect, implement, and verify milestones when iterative agent
  loops revisit those phases.
- Adds explicit task-list states for later reasoning steps and delegated
  sub-tasks.
- Reserves "Finish the response" for actual composing work.

## Validation

- Live browser geometry confirmed the active panel is above the composer,
  full-width aligned, and separated by an eight-pixel gap.
- JavaScript syntax validation passed.
- UI contract tests passed.
