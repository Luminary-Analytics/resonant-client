Resonant Client

Auto-update channel for the Resonant Client desktop app.

This page

WinSparkle inside the Resonant Client app polls appcast.xml on this domain to check for new releases. If you're a human reading this, you probably want the source repo or the releases page instead.

Install

Download the latest resonant-setup-X.Y.Z.exe from the releases page and run it. Future updates will land automatically.
