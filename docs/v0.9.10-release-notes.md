# Resonant Client v0.9.10

## Kimi API error handling

- Distinguishes Kimi account quota and billing failures from transient rate limits.
- Stops retrying immediately when the Kimi account has insufficient balance.
- Shows an actionable recharge or billing message instead of a generic transient error.
- Keeps automatic retries for genuine rate limits and temporary provider failures.
- Removes provider account identifiers and authentication details from user-facing errors.
