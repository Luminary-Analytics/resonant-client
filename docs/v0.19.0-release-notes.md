# SONN Client 0.19.0

SONN Client brings the Resonant desktop workflow together with SONN accounts,
searchable Settings, and built-in creative-editor setup. Existing installations
keep their saved projects, sessions, settings, executable name, and update feed.

Release validation on September 13, 2026: **3,244 Python tests passed**, with two
skips; all 19 Node UI tests, Ruff, JavaScript syntax, and diff checks passed.
The final clean 0.19.0 Windows bundle passed version, HTTP, WebSocket, matching
assets, fixture SONN account/editor controls, Settings search, and draft/focus
checks with clean logs. The production installer compiled successfully.
An isolated installer branding-upgrade fixture removed old Resonant shortcuts,
created SONN Client shortcuts, and preserved fixture data. This fixture redirects
paths and disables uninstall registration; it does not exercise a real
machine-wide installation or legacy per-user cleanup.

Settings now has a dedicated searchable sidebar, focused category pages,
grouped preference cards, and switch controls. Profile/Pets have their own pages;
Connections includes provider sign-in, endpoints, and API keys. It preserves
editing focus and drafts during background refreshes, fetches remote data by
page, and adapts to compact screens with a horizontal category strip. See
[settings navigation](desktop-workflow.md#settings-navigation).

Settings validation on September 13, 2026: 19 Node UI tests and 53 targeted
Python tests passed, along with Ruff, JavaScript syntax, and diff checks.
Browser checks covered desktop, 640px, and 400px widths, both themes, search and
empty results, keyboard navigation, persisted profile edits, and draft/focus
restoration. A fresh clean Windows bundle (55.6 MiB, 256 files) passed HTTP,
WebSocket, matching assets, fixture account/editor controls, and packaged
Settings search/navigation at desktop and compact widths, with clean logs.
These UI checks did not run live coding turns or install an upgrade.


The desktop product is now **SONN Client**, formerly Resonant. It reuses SONN's
continuity mark in the sidebar, favicon, and Windows icons. Window titles,
composer/search labels, About, installer display name, updater display name, and
the core agent identity use the new brand. Existing executable/package names,
installation directory, settings/session paths, AppId, and signed update feed
remain compatible; this does not move or rename repositories.

The bottom-left profile now belongs to the authenticated **SONN account**, not
ChatGPT. It reads SONN's workspace API using the configured private invitation,
shows the user identifier and prepaid available/reserved/charged credits, and
keeps other provider connections and usage separate. Local display name is an
optional alias because SONN does not yet return a full name/avatar. Echo remains
optional, with reduced-motion support and no model calls. See the
[desktop workflow](desktop-workflow.md#profile-settings-and-echo) and
[account contract](sonn.md#sonn-account-and-credits).

A live read using the configured SONN invitation verified identity and billing
fields on September 13, 2026; checkout was in test mode. No model generation,
credit purchase, or account credential change was performed by that check.

Validation before the Settings redesign: the full Python run passed 3,240 tests with two skips and identified
four outdated brand/comment assertions. Those expectations were corrected; all
30 tests in the affected files passed on rerun. All 15 Node UI tests, Ruff,
JavaScript syntax checks, and diff checks passed. The clean Windows bundle
(55.6 MiB, 256 files) passed HTTP, WebSocket, SONN account/credits, creative-editor
fixture controls, and packaged asset checks. Browser checks at desktop and
640×720 covered account refresh, invalid invitation recovery, separated provider
identity, keyboard/focus navigation, and preserved composer drafts. An installer
upgrade and release publication remain separate steps.


Built-in [creative editor setup](creative-editors.md) for Blender, Unity, and
Unreal Engine 5, with connection controls, read-only scene probes, actual MCP
tool/resource discovery, screenshot results, and bounded workflow instructions.
Enabled editor profiles pass to Codex/Claude Code per invocation in Full-auto;
global CLI configuration and explicit model choices remain unchanged.

MCP stdio now drains notifications/logs, matches response IDs, and bounds request
waits. Tool lists support pagination. Native Auto-edit no longer auto-approves
arbitrary MCP actions. Live Blender fixture validation passed; Unity/Unreal
editor execution and billable model turns remain pending.
