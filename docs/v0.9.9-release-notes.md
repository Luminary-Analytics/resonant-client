# Resonant Client v0.9.9

## Kimi K3 provider

- Adds Moonshot's direct Kimi K3 API as a first-class chat and harness backend.
- Streams final text while preserving K3 reasoning across native tool-call turns.
- Supports base64 image input, parallel tools, the 1M-token context profile, and automatic prompt caching.
- Adds secure local API-key settings with `MOONSHOT_API_KEY` environment fallback.
- Tracks Kimi input, cached-input, and output costs at the current provider rates.
- Keeps Ollama as the free local-first default and fallback provider.
