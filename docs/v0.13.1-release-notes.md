# Resonant Client v0.13.1

This release makes computer and browser use easier to recognize, keeps long
session handoffs focused, and adds a durable foundation for richer agent
history.

## Clearer computer and browser activity

- Every active monitor now receives its own purple computer-use border.
- The cursor indicator is a soft purple glow instead of a loading spinner.
- Repeated actions on the same display extend the indicator without redrawing
  its window.
- Resonant's dedicated Chrome profile groups its tabs in purple and labels the
  group with the active session name, including when an existing browser
  connection is reused.
- Title-bar dragging works again across the custom desktop chrome.

## Succinct handoffs first

Computer-use screenshots are collected into a collapsed gallery. The final
summary and changed files remain the primary handoff, while every screenshot
is still available when evidence needs closer inspection. Changed-file paths
can be opened directly from the completion card.

## Durable, scalable session history

Saved sessions now use a versioned append-only event ledger. Completed events
are flushed as work happens, legacy sessions migrate automatically, and a torn
final write is repaired safely on the next append. Long histories open at the
latest task, load older activity in bounded pages, and keep whole-session
counts and deliverables available without mounting the entire transcript.

Session reads were also consolidated so loading or paging history parses one
consistent ledger snapshot instead of repeatedly scanning the same file.

## Harness groundwork

Tool events now carry provider-independent presentation intent for files,
terminal work, browser use, desktop use, Git, and delegated agents. This is the
first adopted layer from the DeepSeek Harness review; background-job unification
and experimental Code Mode remain deliberately staged behind this durable
event foundation.
