# Resonant Client v0.11.7

## Correctness CI

- Every pull request and push to `main` now runs ruff and the full Python
  suite. Previously the only automated check was the PyInstaller smoke build,
  so a 2,800-test suite ran only when a developer remembered to.
- Tagged releases run the same gate before building, so a signed installer can
  no longer be cut from a red tree.
- Fixed 148 lint findings across the test suite. `resonant_client/**` is held
  to ruff's full default rule set; test and support code carry narrow,
  documented per-file exemptions rather than being excluded outright.
- Removed `-x` from the default pytest options. Fail-fast reported one failure
  where twenty might exist, which is the wrong signal on a gate or a refactor.
- The lint rule set is declared explicitly and the ruff dependency is bounded,
  so a new linter release cannot turn the project red without a code change.

## Provider output normalization

- Chat-template control tokens are now stripped identically on every provider
  path. Ollama previously used a narrower rule that recognized only the ChatML
  pair, so Llama-family tokens (`<|eot_id|>`, `<|end_of_text|>`,
  `<|start_header_id|>`) could reach the chat on the primary backend while
  Kimi and EXO were already clean.
- Control tokens split across two stream chunks are now caught. A provider may
  send `<|eot` and `_id|>` in separate chunks — or split after the closing pipe
  — and a per-chunk match sees neither half. The shared filter holds back only
  the trailing run that could still grow into a control token and releases it
  as soon as the next chunk proves it ordinary, so prose ending in `<` is never
  altered or dropped.

## Faster, more accurate code search

- The `grep` tool now prefers ripgrep when it is installed, falling back to the
  previous `findstr` (Windows) and `grep` (POSIX) behavior. `findstr`'s regex
  dialect has no alternation, no `+`, and no groups, so ordinary patterns could
  silently return nothing.
- Dotfile directories such as `.github/` are searched; `.gitignore` filtering
  is kept, and `.git/` internals stay excluded.
- An empty ripgrep result now says that ignored files were skipped, so "not in
  this codebase" is distinguishable from "in a file that was not searched".

## Interrupted agent recovery

- Resuming an agent that was orphaned by a restart is now refused instead of
  flipping it to "running". The old behavior presented a worker with no thread
  behind it, leaving the interface waiting on a run that could never report
  again.
- Interrupted work can be re-dispatched from its persisted assignment, and the
  interrupted transcript is preserved as evidence rather than overwritten by
  its own retry.
- The agent detail panel disables pause, resume, steer, and cancel for agents
  in a terminal state, where those controls could only return an error.

## Process tools restored

- `process_list` and `process_kill` now work in shipped installs. They depend
  on psutil, which was declared in no dependency group, so the packaged
  application answered both with "psutil not installed" — the agent was told
  these tools existed, called them, and got an error back. psutil is now part
  of the `desktop` extra and ships with the bundle.
- This was found by the new CI gate on its first complete run. It had been
  invisible because psutil is usually present on development machines as a
  transitive dependency of unrelated packages.

## Maintainability

- The 22 self-contained WebSocket commands moved out of `websocket_endpoint`
  into a handler registry with an explicit context, making them unit-testable
  without standing up a socket and the whole application state. No command
  behavior changed.

## Validation

- Full Python suite green on CI as well as locally. Ruff clean under both the
  pinned linter version and the next one up.
- All 22 migrated WebSocket commands verified round-tripping against a live
  server; the interface loaded with no console errors.
- The correctness gate found two real defects on its first runs — the
  undeclared psutil dependency above, and its own unpinned rule set. Both are
  fixed in this release.
