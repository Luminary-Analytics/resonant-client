# Resonant Client v0.11.14

Faster, self-contained startup.

## Improvements

- **The app no longer reaches the internet to draw its own interface.** Every
  launch used to open five render-blocking requests to Google Fonts and
  jsdelivr before the window could paint — the font stylesheet alone cost
  273 ms on a good connection, and each of those hosts is a point of failure
  outside your control. The fonts, the markdown renderer, the syntax
  highlighter and its theme, and the HTML sanitizer now ship inside the
  install. Startup makes **zero external requests**, and the interface renders
  correctly with no network at all.

- **The markdown renderer is now a pinned, verified version.** It was
  previously loaded from a "latest" URL, meaning the library that formats every
  reply could change without a corresponding change to Resonant. Each bundled
  asset is now pinned and checked against a recorded SHA-256 at build time, and
  the build fails rather than shipping an install that would fetch them at
  runtime.

## Fixes

- Hardened the chat renderer so it can never insert unsanitized HTML. If the
  sanitizer is unavailable, message content is displayed as plain text instead.
  Model replies and tool output — including the contents of files the agent
  reads — pass through this path, so it fails closed.

## Validation

- Full Python suite: 2,934 passed, 2 platform-skipped. Ruff clean.
- Verified in a running browser: zero external requests on load, all four
  bundled font weights active, and headings, bold, code blocks, and syntax
  highlighting all rendering. Confirmed a script-injection payload is stripped
  when the sanitizer is present and rendered inert as text when it is absent.
- Clean-room bundle build passes the packaging gate with the bundled assets
  present.
