# Resonant Client v0.11.3

## Reliable EXO agent runs

- Stops sustained repetitive or malformed token output and cancels the active
  EXO command remotely instead of allowing an unbounded poisoned generation.
- Quarantines known-malformed assistant history from future provider requests
  while preserving the original session record for inspection.
- Removes a rejected malformed partial from the chat and presents an actionable
  error instead of leaving token fragments in the conversation.
- Ends streams after 120 seconds without semantic progress while keeping healthy
  long-running generations and completion length unlimited.
- Makes Stop responsive while EXO is blocked waiting for stream data.

## Clearer provider state

- Shows EXO instance startup, prefill progress, active model, last-data age, and
  the remaining idle-watchdog window in the working indicator.
- Persists provider and model changes immediately so the session list and
  composer always identify the same live model.
- Documents the EXO stream-idle configuration and its legacy environment alias.

## Validation

- Full Python suite: 2,773 passed and 2 platform-skipped.
- Scoped Ruff, JavaScript syntax, and diff checks passed.
- A live production-shape request against the configured EXO cluster used the
  complete Resonant system prompt and ten-tool core catalog, and GLM 5.2 emitted
  a valid native `file_read` call.
