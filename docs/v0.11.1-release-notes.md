# Resonant Client v0.11.1

## Faster open-model execution

- Replaces the overlapping model instructions with a compact, model-neutral
  coding contract inspired by Pi's minimal execution loop.
- Reduces the normal Ollama/Kimi provider surface from 44 tools to a stable
  ten-tool coding core while retaining specialized tools through on-demand
  discovery.
- Freezes the system prompt for each run and continues directly from tool
  results instead of repeating synthetic continuation and goal messages.
- Delivers steering once at the next safe model boundary, eliminating duplicate
  prompt context while preserving non-interrupting steering behavior.
- Keeps Director Mode, multimodal artifacts, checkpoints, sub-agents, and the
  complete Resonant tool catalog available as optional runtime capabilities.

## More informative working summary

- Shows the concrete current action, including relevant files, searches,
  commands, delegation, and Director activity.
- Shows the latest completed tool, elapsed time, completion count, and failures
  without requiring the run-details panel to be expanded.
- Retains a stable compact layout above the composer.

## Validation

- Full Python suite: 2,753 passed and 2 platform-skipped.
- Scoped Ruff checks, Python compilation, and diff validation passed.
- Prompt and tool-schema size contracts prevent the fast path from silently
  accumulating provider overhead again.
