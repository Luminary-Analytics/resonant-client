# Resonant Client v0.12.3

Computer use now actually reaches the models that can do it.

## Desktop control works with Kimi K3 and local vision models

v0.12.0 introduced computer use for models with vision and reliable tool
calling. In practice it reached almost nobody, for two reasons that only
surfaced by running it against a real model.

**The tools were being removed before the model saw them.** Providers that
support a dynamic tool catalogue — Ollama and Kimi, which covers everything
Resonant talks to — trim each request to a compact core and expose the rest
through a search step. The desktop tools were added to the session and then
stripped back out of the request, so the model had to discover them indirectly.
Asked for a screenshot, a local vision model answered "I cannot take
screenshots"; with the same tools present in the request it took one on the
first turn. They are now part of the core for models that can use them.

**Kimi K3 was excluded from its own feature.** Model capabilities are described
in two places — inferred from the model name, or declared by the provider
adapter — and only the first knew about desktop control. Kimi's declaration
predated it, so the flagship model for this work was the one model that could
not use it. An unstated capability is now derived rather than treated as a
refusal, which fixes every provider-declared model at once.

Verified end to end: asked which application was in the foreground, the agent
listed the open windows, took a screenshot, and named the right one.

Models that cannot drive a screen are unaffected — they are not offered the
tools and their requests do not grow.

## Also

- Corrected two comments that described the default Ollama URL as a LAN host
  and claimed localhost was never a silent fallback. Both were wrong: the
  default is `http://127.0.0.1:11434` and it is silent. The comments were why
  an empty setting looked deliberate rather than unset, which cost real time
  diagnosing an unreachable Ollama that simply had no URL configured.

## Validation

- Full Python suite: 3,012 passed, 2 platform-skipped. Ruff clean.
- Exercised through the GUI against a local Ollama vision model: the agent
  called `window_list` and `computer_screenshot` and correctly identified the
  foreground application from the captured image.
- Regression tests cover both failures — that the desktop tools survive
  catalogue compaction for capable models, that they stay out of it for
  incapable ones, and that a provider-declared profile which never mentions
  the capability still resolves it correctly.
