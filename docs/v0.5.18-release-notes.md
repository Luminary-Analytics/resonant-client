## a1: HarnessOrchestrator public lifecycle

The static helpers + dataclass to_dict methods got coverage in v0.5.14a2. The PUBLIC lifecycle methods that drive the background cycle were untested. This alpha covers them by passing stub callables — the orchestrator constructor takes summary_getter, prompt_builder, backend_selector, role_runner, teacher_escalator as parameters precisely so this kind of testing is possible without real backends.

[tests/test_harness_orchestrator_lifecycle.py](../tests/test_harness_orchestrator_lifecycle.py) ships **18 tests across 6 classes**:

- `TestStartCycle` (6) — returned `HarnessCycleRun` has expected shape (name, project_path, objective, max_loops, 12-char id), max_loops=0 clamped to 1, default name "Harness Cycle", objective whitespace stripped, duplicate-project rejected with `ValueError("...already running...")`, cycle completes when summary_getter returns `"passed"` (next_role=None → COMPLETED).
- `TestListRuns` (4) — empty returns `[]`, runs returned in reverse-chronological order (most-recent-first), `limit` caps the count, returns dicts via `to_dict()`.
- `TestGetRun` (2) — unknown id → None, known id → the HarnessCycleRun.
- `TestCancel` (3) — unknown id → False, already-completed cycle cannot be cancelled (returns False because status is no longer PENDING/RUNNING), running cycle: cancel sets cancel_event and returns True.
- `TestSingleRoleCycle` (3) — end-to-end flow: cycle runs role and completes (role_runner called once with the correct kwargs — `session_role`, `backend_type`, `model`, `cancel_event`, `timeout_seconds`); role_runner exception marks step failed and cycle ends with status=FAILED; cancel_event set inside role_runner stops the loop after one step.

Coverage delta on `resonant_client/harness/orchestrator.py`: **45% → 72%** (+27 pts). Remaining 28% is `_attempt_role_retry` (lines 425-494) and `_attempt_teacher_recovery` (lines 509-583) — both recovery paths that need richer stubs (retry-backend selectors, teacher-escalator dispatch). Worth doing in a future alpha if a contributor wants to drive coverage to ~95%; not pursued in this minor because the high-value lifecycle was the headline gain.
