# Resonant Client v0.9.8

This patch makes clarification phase-aware and prevents agents from ending
completed work with generic continuation questions.

## Highlights

- Limits ordinary clarification to initial alignment, after repository
  investigation and before implementation begins.
- Requires agents to complete the task autonomously once implementation starts,
  including diagnosing failed commands and revising their own approach.
- Reserves mid-run user prompts for imminent destructive data loss, security
  exposure, or another catastrophic irreversible consequence.
- Suppresses generic prompts such as "What's next?", "Should I continue?", and
  "Would you like me to...?" before they reach the UI.
- Directs agents to report outcomes and present optional recommendations or next
  steps as statements in the final response.
- Removes cycle-recovery guidance that previously encouraged stalled agents to
  ask the user what to do.

## Validation

- Full Python test suite passed: 2,746 passed and 2 skipped.
- Focused clarification, model-prompt, and cycle-guard suites passed: 96 tests.
