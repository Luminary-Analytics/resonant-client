# Resonant Client v0.14.0

This release streamlines Resonant around a familiar, conversation-first agent
experience for Kimi, GLM, and other open models while keeping the full local
tool harness available behind the chat.

## Conversation-first sessions

- Responses use a wider, calmer reading column with cleaner typography and
  less implementation noise competing with the answer.
- User requests, live progress, tool activity, final responses, and completion
  evidence now read as one coherent conversation.
- The working indicator uses concise, human-readable phases and elapsed time,
  with detailed actions available on demand instead of permanently expanded.
- Final responses favor clear outcomes, useful summaries, and natural
  follow-up language across Kimi and GLM models.

## Standard agentic workflow

- Director Mode and its configuration, runtime commands, and supervisory UI
  have been retired.
- The permanent Agents hierarchy pane has been removed from the preview area.
- Existing Director-tagged sessions migrate safely back to ordinary sessions
  when opened.
- Standard tools, MCP integrations, browser and computer use, and bounded task
  delegation remain available through the normal agent loop.

## More accurate handoffs

- Read-only and exploratory prompts receive response guidance appropriate to
  their intent instead of being framed automatically as implementation work.
- Completion summaries distinguish changed-and-verified work from informative
  answers and surface validation evidence more compactly.
- Run cards keep the final answer primary while preserving expandable details,
  changed files, screenshots, and review actions.

## Validation

- Live sessions verified multi-turn conversation, file create/read/cleanup,
  native Chrome navigation, computer-use vision, MCP readiness reporting, and
  standard delegated-task behavior against Advanced Tic-Tac-Toe.
- The file smoke test left the target repository unchanged.
- The complete automated suite passes: 3,055 tests, with 2
  platform-conditional skips.
