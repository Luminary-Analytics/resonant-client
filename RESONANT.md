# Resonant repository instructions

Read and follow [AGENTS.md](AGENTS.md), the shared contributor guide for this
repository. It contains current conventions, architecture boundaries, UI and
provider invariants, validation commands, and release/documentation requirements.

Resonant prefers `AGENTS.md` when loading project instructions; this legacy
entry point remains for tools or checkouts that still look for `RESONANT.md`.
Keep common instructions in `AGENTS.md` rather than maintaining duplicate rules.

See [docs/README.md](docs/README.md) for current guides and historical records.
