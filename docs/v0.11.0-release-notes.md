# Resonant Client v0.11.0

## Frontier-directed open-model teams

- Adds opt-in Director Mode, where a selected frontier model plans, reviews,
  and safely integrates work delegated to a user-selected pool of open or
  lower-cost worker models.
- Adds durable dependency-aware task graphs, capability-based worker routing,
  bounded concurrency, attempt history, and project-local performance signals.
- Keeps writing workers isolated in Git worktrees until validation evidence
  passes and the Director explicitly accepts and integrates the result.
- Adds structured review, revision, reassignment, and fail-closed acceptance
  gates so weak or incomplete worker output does not silently reach the user's
  checkout.
- Adds outcome benchmarks comparing single-agent and Director runs without
  imposing implicit context, output, token, time, or cost caps.

## Desktop experience

- Adds Director configuration for the frontier model, worker pool, concurrency,
  review policy, and integration behavior.
- Adds a live Director runtime view with phase, task dependencies, assignments,
  validation evidence, and benchmark summaries.
- Fixes settings navigation so background session events cannot close the
  settings view while the user is configuring the app.

## Documentation and compatibility

- Adds a canonical Director Mode contract and updates the modern runtime and
  product north-star documents.
- Leaves the existing single-agent execution path unchanged when Director Mode
  is disabled.
- Extends explicit model-role routing with named worker profiles while retaining
  existing role-based fallback behavior.

## Validation

- Full Python suite passed before release: 2,752 passed, 2 platform-skipped.
- Focused Director and GUI regression suites passed.
- Ruff, Python compilation, JavaScript syntax, diff validation, and rendered
  browser E2E checks passed.
