# Resonant Client v0.11.13

An internal release. No behaviour changes.

## Internal

- The frontend's event wiring was one 467-line block registering 62 listeners.
  It is now a short list of seven named groups — composer, terminal bar, run
  controls, sidebar, attachments, preview panel, and global surfaces — so
  finding what wires a given part of the interface no longer means reading the
  whole thing.
- Added a consolidated engineering reference covering the v0.11.7–v0.11.13
  restructuring: what moved, the recurring failure mode behind several recent
  bugs, the packaging and refactoring traps that caused them, and the testing
  conventions adopted in response.

## Validation

- Full Python suite: 2,929 passed, 2 platform-skipped. Ruff clean.
- Verified against a running server that the listeners are genuinely attached
  rather than merely present: the send button, the sidebar toggle, and
  context-menu dismissal all still respond, and the interface loads without
  errors.
