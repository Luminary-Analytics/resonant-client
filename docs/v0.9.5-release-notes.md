# Resonant Client v0.9.5

This patch makes active work and agent decisions more compact, consistent, and
easier to scan.

## Highlights

- Collapses the live task details by default while keeping the current status,
  phase, step, and elapsed time visible.
- Lets users expand or collapse the task list from the full status header and
  preserves that choice as progress updates arrive.
- Reduces multiple-choice prompts to the direct question instead of repeating
  the agent's rationale and option descriptions.
- Presents every choice as a separate aligned row with stable A/B/C markers and
  a right-aligned Recommended badge.
- Keeps the complete underlying option value when sending a selection back to
  the agent.
- Adds a shared Grill Me clarification contract for primary and specialist
  agents: inspect first, clarify consequential ambiguity one question at a
  time, and stop when shared understanding is sufficient.
- Routes user-facing questions through Resonant's native `await_user` prompt
  and requires explicit recommended answers for enumerable choices.
