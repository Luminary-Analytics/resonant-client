# Resonant 0.17.1

September 8, 2026. Compact navigation and contributor documentation.
[Release and Windows installer](https://github.com/Luminary-Analytics/resonant-client/releases/tag/v0.17.1).

## Desktop polish

- Flexible titlebar columns prevent search, the Ctrl+K hint, and toolbar controls
  from overlapping.
- Project previews and Project notes use accessible icon buttons with tooltips.
- Folder icons replace text project disclosure arrows.
- Sessions use compact single-line rows; dates and role details move to hover
  text. Pins, working states, and needs-input states remain visible.
- Reduced indentation and duplicate padding leave more room for session titles.
  Project actions appear on hover/focus, with touch access preserved.

## Documentation

- `AGENTS.md` is the shared contributor guide, imported by `CLAUDE.md` and linked
  from the legacy `RESONANT.md` entry point.
- Current navigation, provider, architecture, and release documentation is
  indexed in [docs/README.md](README.md).

## Release reliability

- Made the process self-protection test independent of the Windows runner PID.
  Production process guards remain unchanged.

## Validation

- Full local Python suite: 3,157 passed, two skipped; five Node frontend tests
  passed. Ruff, JavaScript syntax, and whitespace checks passed.
- Browser checks at 1177×756, 800×600, and 640×600 found no horizontal document
  overflow or overlapping search/toolbar controls. Compact sidebar toggling
  and keyboard activation of Project notes worked.
- The earlier desktop pass exercised previews, notes, project collapse/expand,
  session filtering, and the command palette against 10 fixture projects and
  1,200 sessions. Compact session rows measured 32 pixels.
- The clean Windows bundle passed policy checks at 55.5 MiB / 256 files.
  Packaged version, HTTP UI, WebSocket connection, provider command, draft
  persistence, bundled skill installation, clean logs, and shutdown passed.
  Packaged JavaScript/CSS matched the source bytes.
- 146 local documentation links and the AGENTS/CLAUDE entry points were checked.

This release changes UI/documentation and a test fixture, not provider inference.
Live provider quality and repeated latency measurements remain roadmap work.
