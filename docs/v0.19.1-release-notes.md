# SONN Client 0.19.1

Codex/Astra progress now streams as CLI events arrive instead of buffering all
messages until exit. File-change and command results populate live activity and
completion evidence, fixing false missing-edit warnings after a SONN-to-Codex
handoff. CLI tool observations are never executed again by the native engine.
Named standalone checks use observed exit status and file fingerprints;
compound commands with ambiguous status remain unverified. A later CLI failure
is no longer masked by earlier assistant text, and stream cancellation cleans
up the owned CLI process.

Live Astra fixture validation showed the first message in about five seconds,
file-change and command events during work, and a completed turn with recorded
pytest evidence. Source browser fixtures verified in-progress text, activity,
and the successful completion card. These changes do not rewrite saved cards
or re-run the user's original project.

Validation: 3,265 Python tests passed with two skips; all 19 Node UI tests,
Ruff, syntax, and diff checks passed. The clean Windows bundle passed HTTP,
WebSocket, changed-asset matching, and browser startup checks with clean logs.
Live model testing exercised the source engine; the packaged smoke test did
not invoke another model turn.
