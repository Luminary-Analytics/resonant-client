# Resonant Client v0.9.1

This stability release keeps long-running work visible without letting the
agent UI or its background processes interrupt the user.

## Highlights

- Docks the live "Resonant is working" surface directly above the composer so
  growing transcript and tool activity cannot push it around.
- Preserves the run-details expanded or collapsed state across live updates.
- Uses a bounded, scrollable details region to prevent task and sub-agent lists
  from continually resizing the composer dock.
- Stops rebuilding the entire live-run surface for every streamed model token,
  eliminating animation restarts and severe thinking-state flicker.
- Adds compositor-stable orbit and progress animations.
- Introduces one shared Windows background-process policy using
  `CREATE_NO_WINDOW`, hidden startup settings, and optional process groups.
- Applies invisible background execution to agent commands, cancellation,
  validation, tests, linting, Git, hooks, MCP servers, REPLs, PowerShell and
  clipboard helpers, browser probes, computer-use helpers, and recording.
- Keeps intentionally user-facing applications visible while hiding their
  console-based launch and management helpers.
