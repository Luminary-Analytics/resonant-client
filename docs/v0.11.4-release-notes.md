# Resonant Client v0.11.4

## Reliable long-context GLM runs

- Shows measurable EXO prefill progress, transport liveness, time since genuine
  model progress, and the remaining semantic-idle safeguard.
- Changes the compact working summary to say "Still working" during a long
  healthy prefill instead of leaving users with an ambiguous spinner.
- Keeps the full provider context and completion length available without a
  harness-side token cap.
- Warms EXO models through a small native tool call after model selection, while
  allowing real work to preempt speculative warmup immediately.

## Safe EXO recovery and completion

- Automatically replays an uncommitted generation when EXO reports that a
  runner shut down before completing its command.
- Clears abandoned partial prose before replay so recovered responses are not
  duplicated or persisted into model history.
- Limits recovery to three total attempts and presents a clean terminal error
  when the cluster cannot recover.
- Completes turns that already produced a useful answer instead of starting a
  redundant generation for a suppressed trailing question.
- Keeps consequential user decisions available after read-only repository
  investigation and verification.

## Model capability correctness

- Reports EXO prefix-cache support so the runtime and diagnostics reflect actual
  cached-token behavior.
- Sends native images only to EXO models that advertise vision support and uses
  an explicit text fallback for text-only GLM models.

## Validation

- Full Python suite: 2,780 passed and 2 platform-skipped.
- Scoped Ruff, Python compilation, JavaScript syntax, and diff checks passed.
- A live GLM 5.2 probe processed 30,205 input tokens, retained exact markers
  from the beginning, middle, and end, and produced the required native tool
  call after reporting prefill progress through 100 percent.
- Its cached post-tool continuation reused 30,203 of 30,266 prompt tokens and
  returned exactly `LONG_CONTEXT_COMPLETE` in 7.58 seconds.
- EXO reported zero active commands after the validation run.
