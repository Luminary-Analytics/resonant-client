# Resonant Client v0.11.6

## Stable rapid project switching

- Coalesces rapid project-rail clicks so only the final selection launches
  project indexing and model discovery.
- Gives every project switch a unique acknowledgement and ignores stale
  initialization replies, preventing older clicks from snapping the interface
  back to a different project.
- Keeps the pending selection visible immediately and restores the confirmed
  project cleanly if opening the new project fails.
- Preserves project-icon order while switching, including when multiple
  project initializations overlap.

## Cleaner project rail

- Pins **Add project** at the top of the rail.
- Removes the permanent Resonant brand tile.
- Shows only user-registered projects; the built-in Playground, session-derived
  entries, and implicit current-folder placeholders no longer create rail
  icons.
- Leaves an empty project rail with only the Add button for users who have not
  added a project.

## Validation

- Full Python suite: 2,787 passed and 2 platform-skipped.
- JavaScript syntax, Python compilation, and diff checks passed.
- Live browser QA verified rapid clicks within the debounce window and
  overlapping in-flight project changes. The final clicked project remained
  active, icon order stayed fixed, Add remained first, and no browser errors
  were reported.
