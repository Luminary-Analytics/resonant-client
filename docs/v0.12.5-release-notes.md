# Resonant Client v0.12.5

Restores the computer-use indicator, which v0.12.4 broke.

## Fix

**The on-screen glow, banner, and cursor ring stopped appearing in v0.12.4.**
That release fixed a crash by correcting how one Windows call was declared —
and in doing so made it return a full-width handle that a second, still
undeclared call would not accept. Creating the overlay window failed from then
on. Because the indicator is built to fail quietly rather than interrupt a run,
there was no error: computer use kept working and simply stopped announcing
itself.

Anyone who updated to v0.12.4 and used computer use had the agent driving their
machine with no visual signal at all. If that is you, update.

Both calls are now declared, and there is a test that creates the overlay
window for real rather than inspecting declarations — the previous test
inspected them and passed against the broken build.

## Validation

- Full Python suite: 3,012 passed, 2 platform-skipped. Ruff clean. No native
  faults.
- Verified live during an actual agent run on a local vision model: the glow
  appeared 15.7s in, captured mid-run, with the banner reading "Resonant is
  using the computer".
- The new test was confirmed to fail against the v0.12.4 code and pass against
  this one.
