# Resonant 0.17.0

Released September 8, 2026. Commit `f53dc6da6615b971d470b57bc3e09f9f02d4ae2f`.
[Release and Windows installer](https://github.com/Luminary-Analytics/resonant-client/releases/tag/v0.17.0).

## Changes

- Projects and sessions share one sidebar. New session starts a draft and
  persists a conversation on its first message.
- ChatGPT sign-in, account model discovery, and reported remaining usage use
  the installed Codex CLI's account service.
- OpenRouter supports catalog discovery, native tools, reasoning continuation,
  and provider-reported costs.
- Searchable models, favorites, project defaults, and session overrides simplify
  provider selection. Provider changes are blocked during active runs.
- GPT-6 Astra is available through Codex discovery/bootstrap and OpenRouter's
  catalog without changing existing defaults.
- Codex text handoffs include project instructions, relevant notes, recent
  conversation, and retained summaries.

## Validation and limits

The final local Python suite passed 3,157 tests with two skipped. Five Node
frontend tests, lint, JavaScript syntax, the clean Windows build, and packaged
HTTP/WebSocket/startup/skill checks passed. Release and build CI passed. The
separate test workflow passed on rerun after a process-ID-dependent assertion
in the existing kill-guard test; see [known issues](known-issues.md).

Live Codex account/model discovery and OpenRouter public catalog checks passed.
Generation/tool-cycle validation used mocked provider responses, including an
engine run that wrote a real fixture file; paid OpenRouter generation was not
tested. Codex handoffs do not preserve native provider sessions or image inputs.

The installer and signed public update feed were verified. Later toolbar icons,
folder disclosures, and compact session rows shipped in [0.17.1](v0.17.1-release-notes.md),
not in the 0.17.0 installer.
