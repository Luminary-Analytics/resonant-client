# Remaining live qualification

This is a reviewable execution plan, not permission to invoke a provider or
enroll external hosts. Source fixtures and packaged scripted inference do not
establish model quality, comparative benefit or deployed organization readiness.

## Native provider baseline and comparison

Use one explicitly selected local native model and one explicitly selected
hosted native model, each in isolated fixture projects with no personal sessions.
The current configured Ollama and EXO endpoints did not answer a bounded model
inventory probe on September 26, 2026. No inference was invoked. The desktop's
saved default is an Ollama cloud model; its name does not establish local-model
qualification or authorize hosted spending. Keep that saved default unchanged.

For each model, first run the pinned four-scenario single-agent baseline with
three repetitions: independent investigation, two-file CSV export, serial-heavy
ledger migration and interrupted processor repair. Set an enforced allowance of
12 model requests per case and a 180-second cancellation deadline. That is 12
cases and at most 144 admitted requests per model. Main and auxiliary requests
share the allowance. Actual cleanup may exceed the cancellation deadline and
must remain visible. These limits do not enforce a dollar ceiling.

After the baseline, declare the numerical correctness, parallel-task time and
serial-overhead thresholds before dispatching any comparative pilot. Pin that
declaration beside the immutable baseline evidence. Do not select thresholds or
omit failed scenarios after seeing comparative outcomes.

Run both single and swarm modes for the same four scenarios, three repetitions,
under each of the operational and equal-resource controls. Each control has 24
cases, at most 288 model requests, and the same per-case deadline. Including the
baseline and both controls gives a ceiling of 720 admitted requests per model,
1,440 for the two-model qualification. No failed or interrupted case is silently
replaced. Unknown usage or cleanup stops later dispatch until explicitly resolved.
The existing unguarded batch adapter remains a reported unsupported comparison.

The source runner writes a protocol before execution, verifies pinned inputs and
source, uses a seeded case order and independently checks actual artifacts. Every
case must retain failure, intervention, known/unknown cost and cleanup evidence.
Do not infer added swarming benefit from a successful demo or scripted timing.

Before live dispatch, supply the exact provider/model and reachable endpoint for
each lane, confirm the request allowance and any additional spending constraint,
and make the necessary credentials available through the existing protected
configuration/environment source. Do not paste credentials into a chat or CLI
argument. A dollar ceiling requires a provider-side enforceable limit or a
separately implemented and qualified cost-admission boundary.

## Managed organization qualification

Use an explicitly designated disposable tenant, the selected external OIDC/SCIM
configuration, and two independently provisioned machines or VMs. Each host needs
its own member, certificate/private key, protected configuration and local state.
Use the [managed setup](swarming-managed-setup.md) and service
[operations guide](../services/governance/OPERATIONS.md).

Retain evidence of current membership and policy denial, revocation, offline
admission refusal, local Stop, remote Stop acknowledgement versus actual cleanup,
independent request accounting, bilateral sharing and receiver-owned completion.
Exercise restore into a quarantined database, reconcile later deletion and hold
history against the independently credentialed archive, and verify rollback
without replaying retained execution. Do not reopen restored content or grant new
host authority merely because a database import succeeded.

Required external inputs are the designated hosts, issuer/client/audience and
provisioning setup, protected configuration paths, and the operator's deployment,
backup and archive custody choices. Local fixtures do not supply those decisions.
AI Employee research, training, grants and its paused heartbeat remain outside
this qualification.
