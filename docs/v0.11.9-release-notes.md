# Resonant Client v0.11.9

Code search now works properly in installed copies.

## ripgrep ships with the application

- The agent's `grep` tool has preferred ripgrep since v0.11.7, falling back to
  Windows `findstr` when it was not installed. That fallback is much weaker
  than it looks: `findstr`'s regex dialect has no alternation, no `+`, and no
  groups, so ordinary search patterns matched nothing and returned "(no
  matches)" — which the agent reads as "not in this codebase" rather than "that
  search could not be expressed". It also walked `node_modules` and `.venv` at
  full cost.
- ripgrep is now included in the installer, so every install searches the same
  way regardless of what is on the machine. The bundled copy is preferred over
  any other ripgrep already present, so behaviour does not vary between
  machines.
- Practically: searches are faster, respect `.gitignore`, and correctly handle
  the patterns the agent actually writes.

This gap was invisible during development because ripgrep is commonly already
installed on a developer's machine. Installed copies had been quietly falling
back to the weaker path.

## Supply chain and licensing

- The bundled binary is pinned to a specific ripgrep release and verified
  against its published SHA-256 checksum during the build, before extraction.
  A mismatch fails the build rather than producing an installer.
- ripgrep's licenses (MIT and Unlicense) are included with the application.

## Packaging integrity

- The build's packaging check now runs bundled helper binaries rather than only
  confirming the files are present. A binary that is present but cannot execute
  — wrong architecture, truncated by an interrupted extract — previously passed
  the check and then failed silently for users. That class of problem now fails
  the build.

## Validation

- Full Python suite: 2,879 passed, 2 platform-skipped. Ruff clean.
- Verified end to end on a clean continuous-integration machine, not only
  locally: the build fetched and verified ripgrep, included it with its license
  files, passed the packaging check, and produced a bootable application.
