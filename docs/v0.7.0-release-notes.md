# v0.7.0 - flagship agent harness

**Date:** 2026-07-10

**Predecessor:** v0.6.17

**Theme:** make GLM-5.2 and DeepSeek V4 Pro first-class long-horizon coding agents.

## Highlights

- Cloud context defaults now match the advertised flagship windows: 976K for
  GLM-5.2 and 1M for DeepSeek V4 Pro/Flash, with compression derived from the
  effective runtime window.
- DeepSeek thinking content is retained across tool-call turns; GLM and
  DeepSeek sampling/effort settings follow their model contracts.
- Max reasoning is available in the GUI and is automatically used for hard
  mission phases such as planning, reflection, verification, and repair.
- Context is checked mid-turn, old oversized tool output is evicted before
  lossy summarization, and goal/todo recitation keeps long runs aligned.
- A dependency-weighted repo map, interactive skill retrieval, and paginated
  file/search tools provide compact just-in-time context.
- File edits now use a conservative multi-strategy matcher with uniqueness
  guards, fuzzy rescue, replace-all support, and actionable repair hints.
- Tool arguments are coerced and validated before execution, including GLM's
  stringified nested JSON and DeepSeek DSML leak recovery.
- Filesystem and batch-tool boundaries now validate canonical paths and
  symlinks; project command policies support readable allow/prompt/deny globs.
- Codex CLI integration now maps Resonant permission modes to supported Codex
  sandbox and approval settings.
- The transcript has a clearer Codex-style request/work-log/answer hierarchy
  with Resonant's local-first teal visual identity.
- Smoke reports now track edit success, fuzzy rescues, argument failures,
  retries, structured-output repairs, and GLM/DeepSeek model profiles.
