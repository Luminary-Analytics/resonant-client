# Resonant Client v0.10.0

## Durable modern agent runtime

- Adds a persistent agent registry with transcripts, structured handoffs,
  status history, and live pause/resume/cancel/steer controls.
- Adds true concurrent delegation for independent work. Writing agents use
  isolated Git worktrees and serialize integration without touching a dirty
  user checkout.
- Adds universal conversation-linked workspace checkpoints before mutations,
  with files-only, conversation-only, or combined rewind and recovery copies.
- Expands lifecycle hooks into structured JSON policy boundaries around model,
  tool, batch, permission, worker, compaction, checkpoint, validation,
  worktree, user-input, and session events.
- Adds a reproducible flight recorder with hashed manifests, append-only event
  trajectories, first-causal-divergence comparison, and OTLP-compatible export.
- Adds provenance-aware explicit context attachments for files, symbols, diffs,
  checkpoints, workers, artifacts, test failures, terminal logs, and plans.
- Adds Python AST and optional Tree-sitter code intelligence for richer
  repository symbols, dependencies, and call orientation.
- Adds explicit model roles for plan, explore, implement, apply, test, review,
  vision, and summarize phases without silent mid-turn model changes.
- Adds trusted capability packs that can bundle agents, skills, hooks, MCP
  servers, commands, recipes, and UI metadata behind one manifest.
- Adds a modality-neutral artifact bus with capability negotiation for text,
  image, audio, video, terminal, diff, DOM, accessibility, binary, and trace
  evidence.

## Desktop experience

- Expands the Agents preview into a five-tab runtime inspector: Agents,
  Timeline, Traces, Artifacts, and Packs.
- Surfaces worker transcripts and handoffs with direct controls.
- Makes checkpoint compare and three-mode restore accessible from Timeline.
- Makes traces inspectable and exportable from the app.
- Adds clickable context-provider syntax to the Context cockpit.
- Preserves the improved session-state indicators, stable working card,
  cancellable steering queue, and performance changes prepared before this
  release.

## Compatibility and safety

- Keeps the legacy `subagent.end.result` payload stable while adding the
  structured handoff as a separate field.
- Keeps legacy environment-variable hooks working alongside structured hooks.
- Marks interrupted workers as stuck after restart instead of showing ghost
  running states.
- Keeps user Git state authoritative: no automatic stash, reset, or dirty-tree
  merge.
