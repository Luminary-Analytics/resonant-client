# Resonant Client v0.11.5

## Long EXO runs remain user-controlled

- Removes the default 120-second semantic-idle and HTTP read cutoffs that could
  terminate a healthy GLM generation after a long quiet reasoning window.
- Keeps EXO generations unlimited by default while preserving responsive user
  Stop, genuine provider/connection failures, and an explicit operator-defined
  idle limit when one is desired.
- Separates transport liveness from semantic model progress so a keepalive is
  reported honestly without being mistaken for a new token.

## One-click, non-interrupting status updates

- Adds **Check status** to the working card.
- Immediately reports local facts even while the model is blocked in a long
  provider call: EXO connection health, last model-progress age, current step,
  completed tool count, and total runtime.
- Queues one concise progress-report instruction for the next safe agent
  boundary without cancelling, restarting, or replacing the active task.
- Deduplicates repeated clicks while an update is pending, acknowledges when
  the model receives the request, and reports a clean race if the run already
  ended.
- Prevents a late status request from ever becoming a surprise follow-up turn.

## Validation

- Full Python suite: 2,785 passed and 2 platform-skipped.
- Focused EXO, steering, and working-card interaction coverage passed.
- JavaScript syntax, Ruff, and diff checks passed.
- A live browser test against EXO-hosted GLM 5.2 verified the complete path:
  immediate local telemetry, one queued status request, safe-boundary
  application, an in-run structured progress report, and normal task
  completion without cancellation or replacement.
