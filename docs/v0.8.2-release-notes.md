# Resonant Client v0.8.2

This release removes Resonant-imposed model generation limits and uses the
complete context windows advertised by the flagship Ollama Cloud models.

## Highlights

- Removes `num_predict` from every Ollama request path, including interactive
  coding, harness roles, structured generation, classification, warm-up, and
  capability probes.
- Removes per-role generation caps from planners, generators, evaluators, and
  sub-agents.
- Uses all 999,424 advertised context tokens for GLM 5.2 Cloud.
- Uses all 1,048,576 advertised context tokens for DeepSeek v4 Pro and Flash.
- Defers generation stopping to the model and provider instead of imposing a
  Resonant output ceiling.
- Preserves provider `done_reason` telemetry for diagnosing native stops.

## Validation

- Reproduced the previously failing 41K-token GLM conversation without a
  generation cap; GLM naturally emitted a `file_write` tool call and stopped.
- Added contracts preventing `num_predict` from returning to model requests.
