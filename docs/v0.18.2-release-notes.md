# Resonant 0.18.2

Conversation progress stays with the latest output, sessions get clearer titles,
and the composer offers an optional next-prompt watermark.

## Session titles

- New sessions get an action-and-subject title immediately, with greetings and
  request filler removed and no cut-off words or ellipses.
- After the first completed turn, native providers can summarize the first prompt
  into a proper short title. This is one tool-free request on the chosen model,
  with a 32-token output limit and a 12-second wait limit. It does not delay coding;
  new work cancels pending refinement. Provider usage may apply.
- Codex and Claude Code retain the local title: metadata generation never starts
  a second CLI coding loop. Failed or slow requests keep the local title.
- Manual renames are preserved, including across reloads. Late results cannot
  rename another session, and renaming another session no longer activates it.

Title validation: the full regression run passed 3,205 tests with two skips;
the naming suite includes 22 tests covering stale results, errors, and timeouts.
Browser checks used a mock native provider to verify initial
naming, post-turn refinement, sidebar/header refresh, and persistence on reload.
No live provider title-quality evaluation is claimed.

## Conversation polish

- Live working status follows the latest response and remains visible at the
  conversation end during text streaming, tools, and pauses. Scrolling up still
  preserves your reading position; use the new-messages button to return.
- Session rows are indented another 12 pixels under their project.
- Completed turns offer a next-prompt watermark in an empty composer. Tab copies
  it into an editable draft without sending; typing ignores it and Escape
  dismisses it. Shift+Tab retains normal navigation. Suggestions do not replace
  existing drafts or carry between sessions, errors, cancelled runs, or replay.
- Suggestions use the finished reply and change summary locally, preferring an
  explicit next step. This adds no model request, cost, or completion delay.

Validation: browser checks with a local mock streaming API, including a long
response, working status position, manual scroll, stopping, Tab acceptance, and
saved drafts. Automated UI tests cover scope, replay, typing, modifiers, errors,
and queued follow-ups. No live model evaluation is claimed.

Release checks: all 11 automated UI tests, Ruff, JavaScript syntax checks, and
documentation link checks passed. The clean Windows bundle is 55.6 MiB with
256 files. Packaged-app checks cover version, HTTP, WebSocket, changed assets,
bundled skills, drafts, conversation progress, and prompt acceptance.

Authenticated live SONN coding evaluation remains pending the user entering a
key in Settings; see [SONN](sonn.md). Longer-term work is in
[ROADMAP.md](../ROADMAP.md).

The 0.18.1 release attempt stopped at CI test collection because the new tests
used an undeclared async test plugin. Version 0.18.2 runs those tests with
standard-library event loops; no installer or update feed was published for
0.18.1.
