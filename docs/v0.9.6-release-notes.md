# Resonant Client v0.9.6

This patch guarantees that every multiple-choice decision prompt identifies a
recommended answer, even when a model omits or misformats its recommendation.

## Highlights

- Preserves a valid explicit `recommended_option` from the active model.
- Preserves an option already marked Recommended when the separate field is
  omitted.
- Falls back to the first model-ordered option when no valid recommendation is
  supplied, so the engine always presents one recommended answer.
- Normalizes malformed output to exactly one Recommended row.
- Tells models to order their preferred answer first as a reliable fallback.
