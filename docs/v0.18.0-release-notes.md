# Resonant 0.18.0

SONN project connections join the desktop model picker. Enter a project API
base URL and private invitation in Settings, refresh its models, then select
`sonn-auto`. Existing session and project model choices remain unchanged.

## Changes

- Added authenticated model discovery, Chat Completions streaming, standard
  function tools, token usage, local cancellation, and sanitized error handling.
  Credentials stay out of serialized backend specs and UI responses.
- Bounded discovery caches by endpoint and credential; kept network refreshes
  off the UI event loop. Active runs protect their connection settings.
- Added accessible names to Settings fields and secret-clear controls; removed
  an unreachable legacy password-rendering branch.
- Refreshed active documentation, AGENTS.md, and the CLAUDE.md entry point.
  Cataloged historical plans and measurements, corrected obsolete Director UI
  and harness ownership guidance, and repaired obsolete source links.
- Made the autonomous stop-priority test wait for its actual wait hook instead
  of relying on a fixed sleep. Production cancellation logic is unchanged.

## Validation

- Full Python suite: **3,183 passed, 2 skipped**.
- Ruff, JavaScript syntax, seven Node UI recovery tests, and whitespace checks passed.
- Checked 145 Markdown files and 648 relative links with no missing targets.
  Historical measurements retain their dates and are not presented as new runs.
- Source browser: saved URL/key, masked key, connection refresh, preserved model
  choice, keyboard selection, clear/reconnect, and 640-pixel Settings layout.
- Clean Windows bundle: **55.5 MiB, 256 files**. Verified executable version,
  HTTP 200, actual WebSocket connection, SONN discovery against a local mock API,
  packaged Settings/project chooser, draft persistence, bundled skills, changed
  asset parity, and clean startup logs.
- Focused SONN/provider suite: 72 tests, including a real engine file-write loop
  using mock SSE.


Authenticated live SONN discovery and generation remain pending the user's key
entry in Settings. No routed vision, reasoning, or remote cancellation support
is claimed. See [SONN setup and contract](sonn.md).
